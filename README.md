概念设计光影怎么打？Mark Li课程里的布光思路拆解
很多人做概念设计，画完线稿铺完颜色，往画面里随便打几束光，出来的效果要么主体直接融在背景里看不清，要么光影逻辑混乱，亮部暗部到处乱飞，画面的氛围感始终出不来。Mark Li课程里的布光思路完全跳出了“凭感觉打光”的误区，没有堆砌复杂的光影术语，而是把布光拆解成普通人能直接照着落地的清晰步骤，哪怕你之前对光影一知半解，顺着走也能快速做出层次分明、氛围感拉满的概念设计作品。

你可以先从第一步开始，用“单主光定调”，别上来就往画面里堆七八束不同方向的光。很多人刚上手布光，总觉得光越多画面越丰富，结果主光源的方向完全被淹没，整个画面的明暗逻辑乱成一团，观众根本不知道视觉焦点该落在哪。你先在画面里只留一个明确的主光源，确定它的方向、软硬和冷暖属性，比如你要做一个深夜街头的概念场景，就选一盏路边的路灯当唯一主光，让它的光线方向明确照亮画面的核心主体，所有物体的亮暗面、投影全部跟着这个主光的逻辑走，先把整个画面的光影大基调牢牢定下来，后续所有补充光都不能打破这个核心逻辑。

第二步你用“边界光抓眼球”，把核心主体从背景里彻底分离出来。很多人画完主光之后，主体和背景的明暗对比差不多，哪怕细节画得再丰富，画面还是显得平，观众的视线很容易在场景里乱跑，抓不住重点。你顺着主光的逻辑，给核心主体的边缘补一层薄薄的轮廓光，不用太亮，刚好能让主体的边缘从背景里清晰地“浮”出来就行，比如你画一个站在暗巷里的角色，用远处的冷光在他的肩膀和头发边缘勾出一层细亮的边，不用加任何多余细节，角色的存在感立刻就上来了，观众的视线会第一时间被牢牢吸引到你想突出的主体上。

第三步你用“分层补光塑氛围”，不用大面积提亮暗部。很多人做完前两步，暗部全是死黑一片，里面的细节完全看不见，就直接把暗部整体拉亮，结果整个画面的明暗对比直接垮掉，之前定好的氛围感全没了。你不用直接提亮暗部，而是顺着场景的环境属性，给暗部里的不同区域补入微弱的环境光：比如雨夜的暗部里混入一点周围霓虹灯的冷紫色反光，森林场景的暗部里加入一点树叶缝隙漏下来的微弱月光，暗部的细节层次慢慢透出来，同时又不会破坏主光定下的大明暗对比，整个画面的氛围感瞬间就变得细腻又真实。

第四步你做“光影逻辑全局校验”，把所有不符合规则的细节全部修正。很多人布光到最后，总会在角落留下一些逻辑矛盾的小细节：主光从左边照过来，某个小物件的亮面却跑到了右边，投影的方向和主光源完全对不上，这些小错误很容易让整个画面的专业感大打折扣。你站远一点，把画缩小反复看几遍，顺着主光源的方向，挨个核对画面里所有物体的亮暗面、投影方向，把所有和核心光影逻辑冲突的细节全部调整过来，整个画面的光影逻辑就会变得完全自洽，挑不出明显的硬伤。

很多人做概念设计布光总出问题，根本不是对光影的敏感度不够，而是一开始就没理清主次逻辑，把大量精力浪费在了无关紧要的细碎光线上。Mark Li课程里这套布光思路，每一步都只专注解决一个核心问题，你顺着一步步走，不用靠长期的天赋积累，也能快速做出光影层次清晰、氛围感突出的高质量概念设计作品。
